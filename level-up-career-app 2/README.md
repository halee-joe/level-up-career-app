# Level Up — Career Quest

A mobile-first Progressive Web App (PWA) starter for career development.

## Included
- Daily quests based on the weekly career routine
- XP, levels, and daily quest completion
- Daily affirmation and mini learning challenge
- Skill tree, career roadmap, and personalized tech radar
- Local device storage for XP and quest progress
- Offline shell caching after the first visit

## Important limitations
- This starter saves progress in the browser on one device. It does not sync between devices.
- The tech radar opens fresh Google News topic searches and official source pages. It does not yet aggregate or summarize live stories inside the app. That requires a hosted feed/API service.
- This is not yet published to the internet. A PWA must be hosted over HTTPS before iPhone "Add to Home Screen" installation works reliably.

## Publish free with GitHub Pages
1. Create a GitHub account if you do not already have one.
2. Create a new repository, for example `level-up-career-app`.
3. Upload all files in this folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Open the published HTTPS URL in Safari on your iPhone.
7. Tap **Share → Add to Home Screen**. Enable **Open as Web App** if iOS shows that option, then tap Add.

## Customize
Edit `app.js` to change affirmations, mini challenges, daily quest names, XP, and weekday routines. Edit `index.html` for visual changes and career roadmap content.
